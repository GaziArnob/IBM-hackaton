## Generated / Derived Sources

### 3. JUnit 5 Test Suite (Bob-generated)

| Property | Value |
|----------|-------|
| Location | `legacy-app/src/test/java/` |
| Format | `.java` source files |
| Origin | Generated by Bob during the test-generation step |
| How it is used | Captures legacy behaviour as executable specifications; must stay green throughout all refactoring steps. |

---

### 4. Maven Surefire Reports

| Property | Value |
|----------|-------|
| Location | `legacy-app/target/surefire-reports/` |
| Format | XML + plain text |
| Origin | Produced by `./mvnw test` |
| How it is used | Pass/fail metrics consumed by the Streamlit dashboard. Not committed (excluded by `.gitignore`). |

---

### 5. Refactoring Reports

| Property | Value |
|----------|-------|
| Location | `reports/` |
| Format | Markdown, HTML, DOCX (generated by Bob) |
| Origin | Produced by Bob after each refactoring session |
| How it is used | Human-readable summaries of every change applied to the codebase, shared as part of the hackathon submission. |

---

### 6. Bob Session Exports

| Property | Value |
|----------|-------|
| Location | `bob_sessions/` |
| Format | PNG screenshots, text exports |
| Origin | Manually saved from the Bob UI after each session |
| How it is used | Audit trail of every AI-assisted decision made during the hackathon demo. |

## Dashboard Metrics

The Streamlit dashboard (`dashboard/`) reads the following at runtime:

| Metric | Source |
|--------|--------|
| Test pass/fail counts | `legacy-app/target/surefire-reports/*.xml` |
| Lines of code (before/after) | Computed by `dashboard/app.py` |
| Refactoring steps completed | `reports/` directory listing |
